# کُدینو — بات تلگرامی روی Vercel

بات تلگرامی با دکمه‌های شیشه‌ای (inline keyboard)، منوی تنظیمات، امکان تغییر **اسم بات** و **رنگ تم** توسط خود کاربر، و اجرا به‌صورت Serverless روی Vercel.

## چه چیزی داره؟

- `/start` — پیام خوش‌آمد + منوی اصلی (باز کردن مینی‌اپ، تنظیمات، درباره)
- `/settings` — رفتن مستقیم به تنظیمات
- `/help` — راهنما
- منوی **تنظیمات** با دو قابلیت:
  - ✏️ **تغییر اسم بات** — هر کاربر می‌تونه اسم دلخواه خودش رو برای بات ست کنه
  - 🎨 **تغییر رنگ تم** — از بین ۶ رنگ (آبی، قرمز، سبز، بنفش، نارنجی، زرد)
- همه‌چیز با دکمه‌های شیشه‌ای، بدون نیاز به تایپ دستور (به‌جز موقع نوشتن اسم جدید)
- تنظیمات هر کاربر جدا ذخیره می‌شه (به ازای `chat_id`)

## ساختار فایل‌ها

```
api/webhook.js        نقطه‌ی ورودی که Vercel و تلگرام باهاش صحبت می‌کنن
lib/store.js          ذخیره‌سازی تنظیمات (Vercel KV یا حافظه‌ی موقت)
lib/telegram.js        توابع کمکی برای صدا زدن Telegram Bot API
lib/keyboards.js       تعریف دکمه‌های شیشه‌ای هر منو
lib/texts.js           متن پیام‌های هر منو
scripts/set-webhook.js اسکریپت یک‌باره برای ثبت آدرس webhook در تلگرام
scripts/delete-webhook.js اسکریپت برای حذف موقت webhook
vercel.json            تنظیمات اجرای تابع روی Vercel
```

## مرحله ۱: ساخت بات و گرفتن توکن

1. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. بزن `/newbot` و اسم و یوزرنیم دلخواه رو بده
3. یه توکن شبیه `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` بهت می‌ده — این می‌شه `BOT_TOKEN`

## مرحله ۲: تنظیم متغیرهای محیطی روی Vercel

توی پنل پروژه‌ات روی Vercel برو به **Settings → Environment Variables** و این‌ها رو اضافه کن:

| نام متغیر | اجباری؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ بله | توکنی که از BotFather گرفتی |
| `MINI_APP_URL` | اختیاری | آدرس مینی‌اپ (Web App) که دکمه‌ی «باز کردن» بهش وصل می‌شه |
| `KV_REST_API_URL` | اختیاری ولی توصیه‌شده | برای ذخیره‌سازی دائمی تنظیمات کاربرها |
| `KV_REST_API_TOKEN` | اختیاری ولی توصیه‌شده | همراه بالایی |

### درباره‌ی `KV_REST_API_URL` / `KV_REST_API_TOKEN`

اگه این دوتا رو ست نکنی، بات کامل کار می‌کنه، ولی چون Vercel لامبدا رو گاهی «سرد» می‌کنه (cold start)، ممکنه اسم/رنگی که کاربر ست کرده بعد از یه مدت بی‌کاری پاک بشه. برای اینکه تنظیمات همیشه و برای همیشه بمونه:

1. توی پنل Vercel برو به تب **Storage**
2. یه دیتابیس از نوع **KV** بساز (رایگانه، روی Upstash Redis می‌شینه)
3. وقتی بهش وصلش کنی (Connect Project)، خودش `KV_REST_API_URL` و `KV_REST_API_TOKEN` رو به پروژه اضافه می‌کنه — نیازی نیست دستی بنویسی

## مرحله ۳: دیپلوی

```bash
npm install
vercel deploy --prod
```

یا مستقیم از گیت‌هاب ریپو رو به Vercel وصل کن (Import Project).

## مرحله ۴: وصل کردن Webhook به تلگرام

بعد از دیپلوی، آدرس پروژه‌ات چیزی شبیه این می‌شه:
`https://qr1-telegram-bot.vercel.app/api/webhook`

روی سیستم خودت (نه روی Vercel) این رو اجرا کن:

```bash
BOT_TOKEN="توکن_خودت" \
WEBHOOK_URL="https://qr1-telegram-bot.vercel.app/api/webhook" \
node scripts/set-webhook.js
```

اگه جواب `"ok": true` گرفتی، بات آماده‌ست. برو توی تلگرام `/start` بزن.

## سفارشی‌سازی

- **اضافه کردن دکمه‌ی جدید:** `lib/keyboards.js` رو باز کن، هر آرایه یه ردیف دکمه‌ست
- **تغییر متن پیام‌ها:** همه‌شون توی `lib/texts.js` هستن
- **اضافه کردن رنگ جدید:** توی `lib/store.js`، آبجکت `COLORS` رو ویرایش کن
- **اضافه کردن یه منوی کاملاً جدید:** یه `data` جدید مثل `menu:faq` تعریف کن و توی
  `handleCallbackQuery` (فایل `api/webhook.js`) یه شرط `if` جدید براش بنویس

## تست محلی (اختیاری)

چون این پروژه Serverless هست، ساده‌ترین راه تست، دیپلوی روی یه پریویو-برنچ Vercel هست
(`vercel deploy` بدون `--prod` یه لینک پریویو می‌ده که می‌تونی جداگانه webhook روش ست کنی).

## مشکلات رایج

- **بات جواب نمی‌ده:** مطمئن شو `BOT_TOKEN` درست ست شده و `scripts/set-webhook.js` رو با آدرس درست اجرا کردی
- **دکمه‌ی مینی‌اپ نیست:** یعنی `MINI_APP_URL` رو ست نکردی — این دکمه اختیاریه
- **تنظیمات بعد از مدتی پاک می‌شه:** یعنی KV وصل نکردی؛ برو مرحله‌ی «درباره KV» بالا
