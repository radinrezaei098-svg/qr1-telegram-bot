# راهنمای آپدیت بات کیوارکد ساز (نسخه ویزارد مرحله‌به‌مرحله)

## چه چیزی تغییر کرد؟
دیگه هر متنی که بفرستی، بات مستقیم کیوارکد نمی‌سازه. به‌جاش سه تا سوال می‌پرسه:
1. 📝 می‌خوای زیر کیوارکد متنی نوشته بشه؟ (اگه بله، همون‌جا متنش رو ازت می‌گیره)
2. 📏 چه اندازه‌ای؟ (کوچک/متوسط/بزرگ)
3. 🎨 چه رنگی؟ (۶ گزینه)

و بعد کیوارکد نهایی رو با همون مشخصات می‌سازه و می‌فرسته.

⚠️ دستور `/settings` قبلی دیگه استفاده نمی‌شه — این ویزارد جایگزینش شده.

## مرحله ۱: دانلود فونت فارسی (مهم‌ترین قدم)

بدون این فونت، اگه متن فارسی زیر کیوارکد بخوای، به‌جای حروف فارسی باکس‌های خالی نمایش داده می‌شه.

1. برو به این آدرس: https://github.com/rastikerdar/vazirmatn/releases
2. آخرین نسخه رو باز کن، دنبال فایلی به اسم چیزی شبیه `vazirmatn-v33.003.zip` بگرد و دانلودش کن (از قسمت Assets)
3. فایل زیپ رو باز کن (اکسترکت کن)
4. داخلش دنبال پوشه‌ای به اسم `fonts/ttf` بگرد
5. فایلی به اسم `Vazirmatn-Regular.ttf` رو پیدا کن

## مرحله ۲: اضافه کردن فونت به ریپازیتوری

1. برو توی ریپازیتوری `qr-telegram-bot` روی GitHub
2. روی **Add file → Create new file** بزن
3. توی فیلد اسم فایل بنویس: `fonts/Vazirmatn-Regular.ttf`

   ⚠️ نکته: چون این یه فایل باینری (غیرمتنی) هست، GitHub توی مرورگر اجازه نمی‌ده مستقیم پیستش کنی. بهترین راه:
   - به‌جاش از لینک **"uploading an existing file"** توی صفحه اصلی ریپازیتوری استفاده کن
   - فایل `Vazirmatn-Regular.ttf` که دانلود کردی رو مستقیم بکش و بنداز توی باکس آپلود گیت‌هاب
   - قبل از Commit، توی گیت‌هاب می‌تونی مسیرش رو ویرایش کنی تا بره داخل پوشه `fonts/` (یا اول یه پوشه `fonts` بساز و بعد فایل رو داخلش آپلود کن)

## مرحله ۳: آپدیت کدها

سه فایل زیر رو توی ریپازیتوری با نسخه‌های جدیدی که برات فرستادم جایگزین کن:
- `api/webhook.js`
- `package.json`
- `vercel.json`

برای هرکدوم: فایل رو باز کن → ✏️ (Edit) → همه محتوا رو پاک کن → محتوای جدید رو پیست کن → **Commit changes**

## مرحله ۴: صبر برای Redeploy

Vercel با هر Commit خودش دوباره دیپلوی می‌کنه. برو توی داشبورد پروژه، تب **Deployments**، صبر کن وضعیت سبز بشه (معمولاً ۱-۲ دقیقه، چون این‌بار پکیج‌های بیشتری نصب می‌شه).

## مرحله ۵: تست

1. توی تلگرام یه متن یا لینک بفرست
2. روی **✅ بله** بزن، یه متن کوتاه فارسی بفرست (مثلاً «فروشگاه تازیانه»)
3. یه اندازه و رنگ انتخاب کن
4. باید کیوارکدی ببینی که زیرش همون متن فارسی به‌درستی نوشته شده

---

## اگه فونت اضافه نشه چی می‌شه؟
بات خطا نمی‌ده و کرش نمی‌کنه — اگه به هر دلیلی ترکیب تصویر و متن مشکل داشته باشه، به‌جاش کیوارکد ساده رو با همون متن به‌عنوان کپشن تلگرام (نه داخل خود عکس) برات می‌فرسته.

## محدودیت‌ها
- متن زیرنویس حداکثر ۶۰ کاراکتر قبول می‌شه (برای اینکه زیر کیوارکد جا بشه)
- حداکثر ۳ خط نمایش داده می‌شه
